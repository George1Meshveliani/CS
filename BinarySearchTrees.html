Binary Search Trees — Theory, Operations & Practice

A Binary Search Tree (BST) is a rooted binary tree where every node stores a key (and optionally a value) and satisfies a strict ordering invariant:

For every node N: all keys in N's left subtree are less than N.key, and all keys in the right subtree are greater than N.key.

This single rule makes BSTs the foundation of ordered dictionaries, database indexes, range queries, and countless other data structures.

1. Key Terminology

  • Root: The topmost node (no parent). Every tree has exactly one root.
  • Node: Contains a key, a pointer to a left child, and a pointer to a right child.
  • Leaf: A node with no children (both pointers are null).
  • Height of a node: Length of the longest path from that node down to a leaf.
  • Height of the tree: Height of the root. An empty tree has height −1.
  • Depth of a node: Number of edges from the root to that node.
  • Subtree: A node together with all its descendants.
  • Inorder predecessor: The largest key smaller than a given key (rightmost node in the left subtree).
  • Inorder successor: The smallest key larger than a given key (leftmost node in the right subtree).

Node Structure in Code

In Python the node is simply a small class; in C++ it is a struct with raw or smart pointers:

# Python
class TreeNode:
    def __init__(self, key):
        self.key   = key
        self.left  = None
        self.right = None
// C++
struct TreeNode {
    int key;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int k) : key(k), left(nullptr), right(nullptr) {}
};

2. Core Operations

2.1 Search

Searching exploits the BST invariant at every step: compare the target key to the current node, then go left if smaller or right if larger. You eliminate half the remaining tree at each comparison — the same principle as binary search on a sorted array. 

# Python — recursive search
def search(node, key):
    if node is None or node.key == key:
        return node                  # None = not found; node = found
    if key < node.key:
        return search(node.left,  key)
    else:
        return search(node.right, key)

# Iterative version (no call stack overhead)
def search_iter(root, key):
    current = root
    while current:
        if key == current.key:
            return current
        elif key < current.key:
            current = current.left
        else:
            current = current.right
    return None

2.2 Insertion

Insertion walks the same path as search until it falls off the tree (reaches a None pointer), then attaches a new node there. The BST invariant is preserved because the position where the new node lands is exactly the position that search would visit for that key. 

# Python — recursive insert (returns updated subtree root)
def insert(node, key):
    if node is None:
        return TreeNode(key)          # create new node at the gap
    if key < node.key:
        node.left  = insert(node.left,  key)
    elif key > node.key:
        node.right = insert(node.right, key)
    # key == node.key → duplicate; ignore (or update value)
    return node

# Usage
root = None
for k in [8, 3, 10, 1, 6, 14, 4, 7, 13]:
    root = insert(root, k)

3. Tree Traversals

A traversal visits every node exactly once. The order in which nodes are visited defines the traversal type. All three classical traversals are DFS; BFS (level-order) uses a queue instead. 

# Inorder: L → N → R  (produces sorted sequence for a valid BST)
def inorder(node):
    if node:
        inorder(node.left)
        print(node.key)       # visit self
        inorder(node.right)

# Preorder: N → L → R  (useful for copying/serializing a tree)
def preorder(node):
    if node:
        print(node.key)       # visit self first
        preorder(node.left)
        preorder(node.right)

# Postorder: L → R → N  (children processed before parent — safe for deletion)
def postorder(node):
    if node:
        postorder(node.left)
        postorder(node.right)
        print(node.key)       # visit self last

# Level-order (BFS): row by row using a queue
from collections import deque

def level_order(root):
    if not root:
        return
    queue = deque([root])
    while queue:
        node = queue.popleft()
        print(node.key)
        if node.left:  queue.append(node.left)
        if node.right: queue.append(node.right)
The inorder trick: Inorder traversal of any valid BST always yields its keys in strictly ascending order. This is the fastest way to check whether a binary tree is a valid BST: run inorder and verify the sequence is sorted.

Iterative Inorder (Using an Explicit Stack)

Recursive traversals use the call stack implicitly. When recursion depth is a concern (very deep trees), use an explicit stack: 

def inorder_iterative(root):
    result, stack = [], []
    current = root
    while current or stack:
        # go as far left as possible
        while current:
            stack.append(current)
            current = current.left
        # process node
        current = stack.pop()
        result.append(current.key)
        # move to right subtree
        current = current.right
    return result

4. Deletion — The Hardest Operation

Deletion has three cases depending on how many children the target node has. Each case preserves the BST invariant differently.

Case 1: Node is a Leaf (no children)

Simply remove it — set the parent's pointer to None.

Case 2: Node has One Child

Bypass the node — connect the parent directly to the node's single child.

Case 3: Node has Two Children

This is the interesting case. We cannot simply remove the node because both subtrees need a new root. The standard solution:

  1. Find the node's inorder successor — the smallest key in its right subtree (go right once, then all the way left).
  2. Copy the inorder successor's key into the node to be deleted.
  3. Delete the inorder successor from the right subtree (which is now a simpler Case 1 or 2).
def delete(node, key):
    if node is None:
        return None

    if key < node.key:
        node.left  = delete(node.left,  key)
    elif key > node.key:
        node.right = delete(node.right, key)
    else:
        # node to delete found
        # Case 1 & 2: zero or one child
        if node.left is None:
            return node.right
        if node.right is None:
            return node.left

        # Case 3: two children
        # find inorder successor (smallest in right subtree)
        successor = node.right
        while successor.left:
            successor = successor.left
        # copy successor's key here, then delete successor below
        node.key   = successor.key
        node.right = delete(node.right, successor.key)

    return node

5. Balance — Why It Matters & AVL Trees

5.1 The Degenerate (Skewed) BST Problem

Insertion order controls tree shape. If you insert keys already sorted (e.g. 1, 2, 3, 4, 5…), the BST degenerates into a linked list — every node has only a right child. All operations then become O(n), losing the logarithmic advantage entirely.

5.2 AVL Trees — Self-Balancing BSTs

An AVL tree (Adelson-Velsky and Landis, 1962) is a BST that automatically rebalances after every insertion or deletion. It maintains the following invariant:

For every node, the heights of its left and right subtrees differ by at most 1. This difference is called the balance factor.

When an insertion or deletion violates this, the tree performs a rotation — a local restructuring that fixes the imbalance in O(1) time.

The Four Rotation Cases

Imbalance caseRotation to applyTrigger
Left-Left (LL)Single right rotationInserted into left child's left subtree
Right-Right (RR)Single left rotationInserted into right child's right subtree
Left-Right (LR)Left rotate on child, then right rotate on rootInserted into left child's right subtree
Right-Left (RL)Right rotate on child, then left rotate on rootInserted into right child's left subtree
 
class AVLNode:
    def __init__(self, key):
        self.key    = key
        self.left   = None
        self.right  = None
        self.height = 1       # new node starts at height 1

def height(n):
    return n.height if n else 0

def balance_factor(n):
    return height(n.left) - height(n.right) if n else 0

def update_height(n):
    n.height = 1 + max(height(n.left), height(n.right))

# ---- Rotations ----
def rotate_right(y):
    x  = y.left
    T2 = x.right
    x.right = y
    y.left  = T2
    update_height(y)
    update_height(x)
    return x           # new subtree root

def rotate_left(x):
    y  = x.right
    T2 = y.left
    y.left  = x
    x.right = T2
    update_height(x)
    update_height(y)
    return y           # new subtree root

def avl_insert(node, key):
    # 1. Normal BST insert
    if node is None:
        return AVLNode(key)
    if key < node.key:
        node.left  = avl_insert(node.left,  key)
    elif key > node.key:
        node.right = avl_insert(node.right, key)
    else:
        return node   # duplicate

    # 2. Update height
    update_height(node)

    # 3. Rebalance if needed
    bf = balance_factor(node)

    # LL case
    if bf > 1 and key < node.left.key:
        return rotate_right(node)
    # RR case
    if bf < -1 and key > node.right.key:
        return rotate_left(node)
    # LR case
    if bf > 1 and key > node.left.key:
        node.left = rotate_left(node.left)
        return rotate_right(node)
    # RL case
    if bf < -1 and key < node.right.key:
        node.right = rotate_right(node.right)
        return rotate_left(node)

    return node

6. Complexity Analysis

Why O(log n)? A balanced BST with n nodes has height \( h = \lfloor \log_2 n \rfloor \). Each operation traverses at most one root-to-leaf path, so its cost equals the height. Proof by induction: a perfect binary tree of height h holds \(2^{h+1} - 1\) nodes, so \(h = O(\log n)\).

Practice Problems

Problem 1: Validate Binary Search Tree (LeetCode #98)

Medium BST Invariant

Given the root of a binary tree, determine if it is a valid BST. A valid BST has all left descendants strictly less than the node, and all right descendants strictly greater (not just immediate children — the entire subtree).

Example: [5, 1, 4, null, null, 3, 6] → false (node 4 is in the right subtree of 5 but 4 < 5).

Solution — Range Propagation

The naive mistake is to only compare a node to its immediate parent. Instead, each node must lie within a valid range (min_val, max_val) inherited from all its ancestors. The root has range (-∞, +∞). Going left tightens the upper bound; going right tightens the lower bound. 

def isValidBST(root):
    def validate(node, min_val, max_val):
        if node is None:
            return True
        # current node must be strictly within (min_val, max_val)
        if not (min_val < node.val < max_val):
            return False
        return (validate(node.left,  min_val,  node.val) and
                validate(node.right, node.val, max_val))

    return validate(root, float('-inf'), float('inf'))

# Alternative: inorder traversal must produce strictly increasing values
def isValidBST_inorder(root):
    prev = [float('-inf')]   # use list to allow mutation inside nested function
    def inorder(node):
        if not node:
            return True
        if not inorder(node.left):
            return False
        if node.val <= prev[0]:   # equal or decreasing → invalid
            return False
        prev[0] = node.val
        return inorder(node.right)
    return inorder(root)

Time: O(n) — visits every node once. Space: O(h) call stack (h = height).

Problem 2: Kth Smallest Element in a BST (LeetCode #230)

Medium Inorder Traversal

Given the root of a BST and an integer k, return the kth smallest value among all nodes' values. Guaranteed: k is valid.

Solution — Early-Exit Inorder

Inorder traversal yields elements in sorted order. The k-th element visited is the answer. We stop as soon as we have visited k nodes to avoid unnecessary work. 

def kthSmallest(root, k):
    count = [0]
    result = [None]

    def inorder(node):
        if not node or result[0] is not None:
            return
        inorder(node.left)
        count[0] += 1
        if count[0] == k:
            result[0] = node.val
            return
        inorder(node.right)

    inorder(root)
    return result[0]

# Iterative version (avoids recursion limit on deep trees)
def kthSmallest_iter(root, k):
    stack, current = [], root
    while current or stack:
        while current:
            stack.append(current)
            current = current.left
        current = stack.pop()
        k -= 1
        if k == 0:
            return current.val
        current = current.right

Time: O(h + k) — descend to leftmost leaf in O(h), then count k nodes. Space: O(h).

Problem 3: Lowest Common Ancestor of a BST (LeetCode #235)

Medium BST Navigation

Given the BST root and two nodes p and q, find their Lowest Common Ancestor (LCA) — the deepest node that has both p and q as descendants (a node is a descendant of itself).

Solution — Exploit the BST Ordering

Unlike a general binary tree, the BST ordering tells us exactly which way to go. If both p and q are smaller than current, LCA is in the left subtree. If both are larger, it's in the right subtree. Otherwise, the current node splits them — it IS the LCA. 

def lowestCommonAncestor(root, p, q):
    node = root
    while node:
        if p.val < node.val and q.val < node.val:
            node = node.left      # both in left subtree
        elif p.val > node.val and q.val > node.val:
            node = node.right     # both in right subtree
        else:
            return node           # split here → current node is LCA
    return None

# Recursive version (equally clean)
def lowestCommonAncestor_rec(root, p, q):
    if p.val < root.val and q.val < root.val:
        return lowestCommonAncestor_rec(root.left,  p, q)
    if p.val > root.val and q.val > root.val:
        return lowestCommonAncestor_rec(root.right, p, q)
    return root

Time: O(h). Space: O(1) iterative, O(h) recursive. Much faster than the general-tree O(n) LCA algorithm because BST ordering guides the search.

Problem 4: Convert Sorted Array to BST (LeetCode #108)

Easy Divide & Conquer

Given an integer array nums sorted in ascending order, construct a height-balanced BST (every node's subtrees differ in height by at most 1). Return any valid answer.

Solution — Midpoint Divide & Conquer

Always pick the middle element as the root of the current subtree. This guarantees equal-sized left and right subtrees, yielding a height of ⌊log₂ n⌋. Recurse on the left half and right half. 

def sortedArrayToBST(nums):
    def build(left, right):
        if left > right:
            return None
        mid = (left + right) // 2
        node = TreeNode(nums[mid])
        node.left  = build(left,    mid - 1)
        node.right = build(mid + 1, right  )
        return node

    return build(0, len(nums) - 1)

# Example trace for nums = [1, 2, 3, 4, 5, 6, 7]:
# build(0,6) → mid=3 → root=4
#   build(0,2) → mid=1 → root=2
#     build(0,0) → leaf 1
#     build(2,2) → leaf 3
#   build(4,6) → mid=5 → root=6
#     build(4,4) → leaf 5
#     build(6,6) → leaf 7
# Result: perfectly balanced tree of height 2

Time: O(n) — each element becomes a node exactly once. Space: O(log n) call stack (balanced tree height).

Problem 5: Delete Node in a BST (LeetCode #450)

Medium Deletion / Inorder Successor

Given a BST root and a key, delete the node with that key and return the updated tree root. It is guaranteed the tree has no duplicate keys.

Solution — Three-Case Deletion

def deleteNode(root, key):
    if root is None:
        return None

    if key < root.val:
        root.left  = deleteNode(root.left,  key)
    elif key > root.val:
        root.right = deleteNode(root.right, key)
    else:
        # Found the node to delete
        if root.left is None:        # Case 1 & 2a: no left child
            return root.right
        if root.right is None:       # Case 2b: no right child
            return root.left
        # Case 3: two children — replace with inorder successor
        successor = root.right
        while successor.left:
            successor = successor.left
        root.val   = successor.val                  # copy successor's value
        root.right = deleteNode(root.right, root.val)  # delete successor

    return root

# Why inorder successor (not predecessor)?
# Both work. The successor is the smallest node that is still
# larger than all left-subtree nodes, so placing it at the root
# maintains the BST invariant without any further restructuring.

Time: O(h). Space: O(h) recursive call stack.

Problem 6: Range Sum of BST (LeetCode #938)

Easy Pruning / Range Query

Given the root of a BST and two integers low and high, return the sum of all node values in the inclusive range [low, high].

Solution — BST-Guided Pruning

Unlike a plain binary tree, the BST ordering lets us skip entire subtrees. If a node's value is less than low, the left subtree cannot contribute (all values even smaller). If greater than high, the right subtree cannot contribute. This pruning makes the solution significantly faster than a full O(n) scan. 

def rangeSumBST(root, low, high):
    if root is None:
        return 0
    total = 0
    if low <= root.val <= high:
        total += root.val       # current node is in range
    if root.val > low:
        total += rangeSumBST(root.left,  low, high)  # left may have values ≥ low
    if root.val < high:
        total += rangeSumBST(root.right, low, high)  # right may have values ≤ high
    return total

# Iterative version using an explicit stack:
def rangeSumBST_iter(root, low, high):
    stack, total = [root], 0
    while stack:
        node = stack.pop()
        if node is None:
            continue
        if low <= node.val <= high:
            total += node.val
        if node.val > low:
            stack.append(node.left)
        if node.val < high:
            stack.append(node.right)
    return total

Time: O(n) worst case, but much better with effective pruning — only nodes on the two boundary paths plus in-range nodes are visited. Space: O(h).

Problem 7: Recover Binary Search Tree (LeetCode #99)

Hard Inorder + Morris Traversal

Two nodes of the BST were swapped by mistake. Recover the tree without changing its structure (restore the original BST). Follow-up: solve in O(1) extra space.

Solution — Inorder Scan for Inversions

Inorder traversal of a valid BST gives a sorted sequence. If exactly two nodes were swapped, there will be at most two inversions (places where prev.val > current.val). The first node of the first inversion and the second node of the last inversion are the swapped pair. 

def recoverTree(root):
    first = second = prev = None

    def inorder(node):
        nonlocal first, second, prev
        if not node:
            return
        inorder(node.left)

        # Check for inversion
        if prev and prev.val > node.val:
            if first is None:
                first = prev   # start of first inversion
            second = node      # end of last inversion (updated on second inversion too)

        prev = node
        inorder(node.right)

    inorder(root)
    # Swap the values back
    first.val, second.val = second.val, first.val

# -------------------------------------------------------------------
# O(1) Space — Morris Inorder Traversal
# (threads right pointers of leaves to their inorder successors
#  temporarily, then restores them)
def recoverTree_morris(root):
    first = second = prev = None
    current = root

    while current:
        if current.left is None:
            # visit current
            if prev and prev.val > current.val:
                if first is None: first = prev
                second = current
            prev = current
            current = current.right
        else:
            # find inorder predecessor
            pre = current.left
            while pre.right and pre.right is not current:
                pre = pre.right
            if pre.right is None:
                pre.right = current      # thread: predecessor → current
                current   = current.left
            else:
                pre.right = None         # unthread
                # visit current
                if prev and prev.val > current.val:
                    if first is None: first = prev
                    second = current
                prev    = current
                current = current.right

    first.val, second.val = second.val, first.val

Time: O(n). Space: O(h) recursive, O(1) with Morris traversal. Morris traversal is a remarkable technique that avoids both a stack and recursion by temporarily modifying the tree's right pointers.

Problem 8: Binary Search Tree Iterator (LeetCode #173)

Medium Iterative Inorder

Implement a BST iterator that behaves like a sorted iterator. next() returns the next smallest number. hasNext() returns whether one exists. Both should run in O(1) average time and use O(h) memory.

Solution — Controlled Inorder with Stack

The trick is to only materialise the path to the leftmost unvisited node in the stack. next() pops the top, visits it, then pushes the left-spine of its right subtree. This lazy evaluation keeps memory at O(h) and amortises cost across calls. 

class BSTIterator:
    def __init__(self, root):
        self.stack = []
        self._push_left(root)

    def _push_left(self, node):
        # push all left-spine nodes onto the stack
        while node:
            self.stack.append(node)
            node = node.left

    def next(self):           # O(1) amortised
        node = self.stack.pop()
        self._push_left(node.right)  # explore right subtree's left spine
        return node.val

    def hasNext(self):        # O(1)
        return len(self.stack) > 0

# Usage:
# iterator = BSTIterator(root)
# while iterator.hasNext():
#     print(iterator.next())
#
# Trace on tree [4, 2, 6, 1, 3]:
# Init: stack = [4, 2, 1]  (left spine from root)
# next() → pop 1, push left-spine of None → stack=[4,2], returns 1
# next() → pop 2, push left-spine of 3   → stack=[4,3], returns 2
# next() → pop 3, push left-spine of None→ stack=[4],   returns 3
# next() → pop 4, push left-spine of 6   → stack=[6],   returns 4
# next() → pop 6, push left-spine of None→ stack=[],    returns 6

Time: O(1) amortised per call (each node is pushed and popped exactly once across all calls). Space: O(h) — the stack holds at most one left-spine path at a time.
